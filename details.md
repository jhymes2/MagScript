this is a program written in python to view lines from a script as flashcards

This application will take a text file of the script with the character names showing up before the lines. This application will parse the file and make a new text file of a characters queues and their line. When run, the program shows a line from a character before "Caitlin" and caitlin's line blacked out. when the space key is pressed caitlin's line is revealed. Pressing space again shows caitlin's next que and blacked out line.

Two modes, chronological and random.
